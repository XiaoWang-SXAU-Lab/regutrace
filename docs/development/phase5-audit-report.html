5.3 审计发现：坐标覆盖不是 30

独立核对 phase5-coord-audit.tsv 得到 52 个 base TFs 的 architecture_groups=0，而非报告早期写的 30。 另有 22 个 coordinate-rerun TFs 不在 1,143-row baseline 内。坐标状态为 1,089 successfully joined + 2 key mismatches + 52 unavailable；1,091 是 audit 的 one-group TF 数。2 个 mismatch 是 Fta_4G0031600、Fta_5G0037620（坐标行与 base 的 motif/reference key 不一致）。

影响：52 个 unavailable TF 的 best/reps 不能用坐标分组，使用 documented opaque single-group fallback（best/reps 各选一个最佳 exploratory motif）；它们仍被计入 1,143 和 target 统计。这是 P2，已在文档中纠正。

6.3 审计判断

  • P1（科学） site/promoter q 是条件性上界：只对 hit 排序；在 hit 表完整、window 数精确且无缺失检验时可作为 full BH 的上界，但不建模窗口/基因依赖、GC/长度或 motif 家族依赖，也不提供无条件 FDR 控制。
  • 已披露 默认 p=1e-4 未变；BH q≤0.05 仅作为可选解释层，不能替代原始候选背景。
  • 缺口 没有 block/bootstrap 或 dependence-aware null；FIMO 未安装/未执行。
